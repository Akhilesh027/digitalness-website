HOW TO RUN
----------
Open terminal inside this project folder and run:

npm install
npm run dev

Then open the localhost URL shown by Vite.

For frontend + included Express server together:

npm start

IF BROWSER SHOWS OLD STYLES
---------------------------
1. Stop the server with Ctrl+C
2. Start again: npm run dev
3. Hard refresh browser: Ctrl+Shift+R

DO NOT CREATE index.css.
The project imports src/styles/global.css from src/main.jsx.
